# Branching Strategy

## Ziel

Die Branching-Strategie sorgt für:

- Strukturierte Zusammenarbeit
- Nachvollziehbare Änderungen
- Sichere Releases
- Einfaches Rollback

---

# Branch-Typen

## main

- Produktionsreifer Code
- Releases werden hier getaggt

---

## develop

- Integrationsbranch für Entwicklung

---

## feature/*

Für neue Funktionen.
